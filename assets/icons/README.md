# Icons

`lucide.json`: 250 stroke icons from [Lucide](https://lucide.dev) (npm `lucide-static@1.54.0`), name →
`[[tag, {attr: value}], ...]` on Lucide's 24 px grid, geometry only. Rebuilt by `python tools/build_icons.py`
(the whitelist is the Georgian stem map in `tt_shorts/icons.py` plus a few extras in the script).

- Licence: ISC (Lucide Icons and Contributors); the icons derived from Feather are MIT (Cole Bemis). Both texts are
  in `LICENSE`, which must stay next to the icons. Commercial use is allowed; no on-screen credit is required.
- Veasy draws them in the brand pack's ink (the accent only for the dot), so no icon carries a color of its own.
