# through-object: one thing runs through the film

**Shape:** one drawn object recurs in every beat and carries the idea; or it crosses the frame and makes the cut.
**Choose it when:** the story has a physical thing (a valve, a bridge, a bus, a bill), or an abstract one that a
single object can stand for, and the film is more than 20 seconds.
**Devices:** `persistent-object` (kit: `draw`, `sign`), `object-wipe`, `graphic-match`, `motion-bridge`.
**Route:** `draw` and `sign` scenes today with the same drawing; the wipe and the match cut are composed.
**News:** `persistent-object` yes; `graphic-match` only when both facts really share the shape.
**Demands:** the narration names the object (`check` asks); the drawing passes `art.py`; the object is not the
film's own tool (a quote, a list, a map, a sign are not the story's thing).
**Avoid:** a mascot, a face, a crowd, the same object in every film of the week.
