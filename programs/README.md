Programs: what a video is made from and what it may claim (`tt_shorts/programs.py`). A program is a JSON file here
plus its writer brief in `briefs/`; `python -m tt_shorts.engine options` lists them (`programs`) and refuses a program
the engine can't do. Built-in: `news` (the default), `explainer`, `law`, `blog`. How to choose and add one: the
`veasy:programs` skill.
